物见隐私政策：让本地物品档案与 AI 识别各守边界

发表于 2026-09-06 更新于 2026-09-12 分类于 独立开发 阅读次数：
本文字数： 字数： 2k 阅读时长 ≈ 阅读≈ 2 分钟
物见如何处理相机、物品图片、本地记录与 AI 识别请求。

物见（Wujian）是一款帮助你记录物品、整理房间和箱子，并在需要时借助 AI 识别物品的移动应用。它会接触到相机和图片，因此隐私边界不能只藏在一页法律文本里，而应该成为产品设计的一部分。

先说结论

  • 物品记录默认保存在你的设备本地，不要求注册独立账号。
  • 只有当你主动拍照并且已经配置 AI 识别服务时，相关图片和识别请求才会进入识别队列并发送到你配置的模型服务或自定义接口；配置完成后，拍照会自动加入队列。
  • 物见不出售个人信息，不投放广告，也不建立跨应用的行为画像。
  • API Key 保存在设备的安全存储中，不应出现在截图、分享内容或公开代码里。
  • 你可以在应用内删除物品、清空数据，或卸载应用来移除本地数据；模型服务一侧的保存期限则由对应服务商决定。

这篇政策适用于什么

本政策适用于“物见（Wujian）”移动应用及其当前版本中的物品记录、图片识别、模型配置和导出功能。开发者为 GreatAndyC。本政策的生效日期为 2026 年 9 月 6 日；如果未来版本新增会明显改变数据处理方式的功能，应用会更新这篇政策。

物见处理哪些信息

物见可能处理以下信息，但处理范围取决于你实际使用的功能：

  • 相机与图片：当前 Android 版本中，你使用应用相机拍摄的物品图片，用于建立物品记录或进入 AI 识别队列。相机权限只用于拍照，不用于后台持续采集。
  • 物品记录：物品名称、分类、房间、箱号、备注、标签和创建时间等你主动填写或确认的内容。
  • AI 请求内容：当你主动拍照且当前已配置识别服务时，应用发送给模型服务的图片、提示词和模型参数。识别结果会回到应用，用于生成或完善物品记录。
  • 模型配置：你填写的服务地址、模型名称和 API Key 等连接配置。API Key 属于敏感信息，建议只使用自己信任的服务，并定期轮换。

物见当前不要求登录，不维护独立的用户账号系统，也不主动收集姓名、电话号码、通讯录、精确位置、广告标识符或支付信息。

本地优先，但不是离线承诺

“本地优先”指的是：物品目录和普通整理操作以设备本地数据为中心，不依赖物见自己的云端账号或后台数据库。它不等于所有功能都完全离线可用。

当你使用 AI 识别时，应用必须通过网络把相关图片和请求内容发送给模型服务。当前 Android 版本默认使用火山方舟兼容接口；你也可以配置自己的兼容接口。该服务如何记录、保留和处理请求，受它自己的隐私政策和服务条款约束。对于身份证件、合同、家庭住址等高度敏感内容，请先确认服务商是否值得信任，再决定是否上传。

AI 识别时会发生什么

一次典型的识别流程如下：

  1. 你在应用中主动拍摄一张物品图片。
  2. 如果已经配置 AI 识别服务，应用会在拍摄后自动将图片加入识别队列；如果没有配置，图片只保留在本地待确认队列。
  3. 应用把必要的图片和请求参数发送到当前配置的模型服务。
  4. 服务返回识别结果，应用让你检查、修改后再保存到本地物品记录。

物见不会因为你打开应用、浏览本地目录或编辑普通记录，就自动把整份物品库上传给 AI。只有主动拍照并已配置识别服务时，相关图片才会按当前配置发送给模型服务。你应当把模型服务商视为本次请求的数据接收方，并直接查看其最新的隐私政策。

API Key 与网络安全

物见将 API Key 保存在设备提供的安全存储中，并在发起请求时使用。应用不会把 API Key 作为文章、导出文件或公开链接的一部分主动发布；但任何能操作你设备的人，仍可能影响本地应用配置，因此请为设备设置可靠的锁屏保护。

连接模型服务时，优先使用 HTTPS 接口。自定义服务地址由你自己提供，物见无法替你保证第三方服务器的安全性、可用性或数据保留规则。若怀疑 API Key 泄露，请立即在对应服务商处撤销并重新生成。

分享、导出与第三方应用

当你主动导出 PDF、Excel 或 Markdown，或使用系统分享功能时，导出的内容会交给你选择的系统应用或第三方应用处理。接收方可能获得物品名称、图片、位置和备注等导出内容；这部分处理不由物见控制，请在分享前检查文件内容和目标应用。

物见当前不接入广告 SDK、跨应用跟踪 SDK 或独立的行为分析后台。

保存期限与删除

本地物品记录会保留在设备上，直到你在应用中删除、清空应用数据，或卸载应用。操作系统备份、设备迁移和你主动导出的文件可能产生额外副本，这些副本应按对应系统或应用的机制管理。

发送给模型服务的请求及其日志、缓存或训练用途，由对应服务商按照其政策和你的账户设置处理。若需要删除服务商一侧的数据，请直接使用该服务商提供的删除、隐私或账户管理渠道。

开发者信息、联系与更新

如果你对这篇政策、数据处理方式或某次 AI 请求有疑问，可以通过 GreatAndyC 的 GitHub 页面 联系开发者。联系时请不要附上 API Key、登录凭证、身份证件或其他不必要的敏感信息。

这篇政策会随应用功能和数据处理方式变化而更新。重大变化会在应用或本页面中以清晰方式说明；页面顶部的日期代表最近一次修订日期。
