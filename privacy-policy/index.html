物见隐私政策

物见如何处理相机、物品图片、本地记录与 AI 识别请求。

物见隐私政策

生效日期：2026 年 9 月 6 日

物见（以下简称“本应用”）是一款用于拍照、识别和整理个人物品的移动应用。本政策说明本应用如何处理你在使用过程中产生的信息。

1. 本地保存的信息

物品记录、分类、原始图片、导出文件和应用设置主要保存在你的设备本地。本应用不要求你注册本应用独立账号，也不会因为你在本地建立物品档案而自动上传这些内容。

2. 相机权限

本应用使用相机权限拍摄物品照片。只有在你使用拍摄功能时才会调用相机；拒绝权限不会影响其他不需要相机的功能。

3. AI 识别与第三方服务

当你主动执行 AI 识别时，本应用会将相关图片和识别请求内容发送到你在应用设置中选择或填写的视觉模型服务。你填写的服务地址、模型和 API Key 由你自行决定；API Key 由本应用保存在设备的安全存储中。

模型服务商可能独立保存或处理收到的内容，并可能产生费用。其处理方式、保留期限、跨境传输和训练用途由对应服务商的隐私政策和服务条款决定。本应用不代表任何第三方服务商作出数据保留、训练用途或合规承诺。

4. 分享、广告和分析

本应用不会出售你的物品记录或图片。当前版本未集成广告 SDK 或行为分析 SDK。你使用系统分享功能导出或分享文件时，文件会交给你选择的系统或第三方应用处理。

5. 保存期限和删除

本地内容会保留到你在应用中删除、清理或卸载本应用为止。卸载应用可能同时删除设备上的本地数据，请在卸载、升级或重装前备份重要内容。已发送给第三方模型服务的内容，其删除和保留由该服务商的政策决定。

6. 安全

本应用尽量通过安全存储保存 API Key，并要求远程模型端点使用 HTTPS。你仍应只配置可信的服务地址，不要在物品图片或请求中提交不必要的敏感信息。

7. 政策更新与联系

本政策可能因功能或法律要求变化而更新。更新后的版本会在本页面发布并标注新的生效日期。如需联系开发者，请通过 GitHub 联系。
