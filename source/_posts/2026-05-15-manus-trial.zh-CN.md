自从 LLM 在世界范围内的爆火宣布 AI 时代已来，一种普遍式的焦虑肉眼可见地从科技圈弥漫到了整个社会。

笔者也在积极学习和探索 AI 在实际生活中的用处，尤其是各种 AI 工具对真实生产和软件开发的帮助。

笔者在若干月前曾经参加过某咨询公司的复试，复试要求是选择一个行业进行调研并且制作对应的 PPT 用于终面的讲解。

当时笔者选择的行业就是高新科技-软件开发，并对其进行了有一定深度的调研。

## 新软件开发模式理论

不管是社交媒体上各大科技从业者或 KOL 传递的消息，还是实际从业者在真实工作流中对 AI 工具的使用情况，我们都可以了解到，现在编程 Agent 已经和开发深度绑定。甚至有消息称谷歌、Anthropic、OpenAI 等公司的员工已经几乎 100% 代码都由 Agent 编写。

过去的 V 型开发模式（设计-编程执行-部署测试）的时间卡点短板——执行阶段已经可以由 Agent 非常快速地完成，预期未来设计与部署测试的部分也可以由 Agent 非常大比例地参与。

![](/images/posts/2026-05-15-manus-trial/manus-01.png)

## 学习实践

虽然理想非常美好，但是实际软件开发过程中还是有非常多的细节问题需要解决。虽然笔者成功地通过 vibe coding 的方式开发出了一款能用的 iOS app 并且上架海外 App Store，但是这个过程显然没有达到预期的软件开发模式的效率。因此，笔者打算系统地学习一下现代软件开发模式，遂找到了斯坦福大学的这门课程。

CS146S: The Modern Software Developer
网址：https://themodernsoftware.dev/

![](/images/posts/2026-05-15-manus-trial/manus-02.png)

众所周知，斯坦福大学作为坐落在 Palo Alto 的将产学研和商业化做的最好的大学，互联网上提供了大量的免费公开高质量学习资源。这门课就是由斯坦福大学的研究员 Mihail Eric 开设的。

关于他的个人简介可以参见：https://www.mihaileric.com/

学习这门课，Eric 获得了名气和影响力，斯坦福大学收获了潜在的商业回报，我们蹭上了高质量的学习资源，可以说是一举三得。

## Manus

作为一个比较贪心的人，我希望通过项目的方式来学习某个特别的技术，否则我的驱动力会非常差。正好，Manus 作为一个处于舆论场风口浪尖的产品，被质疑套壳以及被免费的“Openclaw”完爆，而笔者刚好有想要把这门课的资源全部下载到本地，尝试使用 NotebookLM（https://notebooklm.google/）
高效学习其内容的想法。于是弄到一个体验账号，本着唯物主义的“没有调查就没有发言权”的想法，就开始了我的测试。

## 实力如何？

首先是下载和登陆，非常丝滑顺利。产品 UI 和 UX 设计都和目前流行的各种 Chatbot 的网页端设计非常类似，几乎可以在没有前置经验的情况下无缝操作。

接着告知 Manus 我的需求：分析网站结构，抓取网页内容并最终打包成为一个可以离线能访问的 HTML 页面。

在这个过程中 Manus 会不断输出自己的思考和执行过程，并且会有一个远程的虚拟电脑帮你执行这些内容。中间还涉及到我希望让 Manus 帮我把下载的 YouTube 视频进行中英双语字幕填充等，不过最终由于 Quota 不够而中断了。但是我最初希望得到的结果“完整的支持中英双语 HTML 文件的网页”，Manus 在执行成功之后直接打包文件给我，我对文件进行下载就可以了。

## Openclaw 和 Manus 的区别

所以通过这个过程可以知道，Openclaw 和 Manus 的最大区别就在于，这两者的定位分别是“工程师的工具”和“成熟商用的产品”。

在扎克伯格以天价收购 Manus 之后，很多人都觉得 Manus 不过是一个套壳应用，甚至第二天 GitHub 上就出现了一个开源版本的 Manus。

那么它为什么可以卖这么贵？扎克伯格是傻子吗？

依笔者所见，Manus 能卖这么贵的优点在于：
1. 是第一个在全球都有名气的 Agent 应用。
2. 对比 Openclaw，它提供了“开箱即用”和稳定可靠的服务。
3. Manus 已经积累了一定的用户数、商业口碑与用户数据，具有先发优势。

笔者认为 1 和 3 都是一样的，就如同现在大部分不懂 AI 技术原理的人，提起 AI，也一定知道 GPT 的名字，那么如果当它们要选择使用 AI 的时候，必然会第一个搜索和使用 OpenAI 的 GPT 这个产品。

而 2 是区分“产品”和“工具”的分割线。笔者作为具备一定知识和自认为有非常强的耐心的人，都在配置 Openclaw 环境的过程中非常痛苦，并且经常遇到服务不稳定的情况。而对于用户来说，“开箱即用”和“配置三小时结果啥都干不了”带来的体验是完全天差地别的。甚至在多数情况下，哪怕只是链路上多一个按钮都会导致用户的大量流失，更不用说这种“工程师的工具”了。

同时 Openclaw 会有安全性的问题，很可能导致信息和数据泄漏或者非授权的删除。而 Manus 通过付费提供服务，通过远程电脑承担了这部分的数据安全和稳定性风险，所以它能有这么多的溢价。
